\# Cabinet of Curiosities - Assignment 2



This is an Unreal Engine greybox prototype for Intermediate Games Programming Assignment 2.



\## Project Description



The project is a Minecraft-inspired Blueprint prototype focused on simple interaction systems inside a greybox testing room.



\## Implemented Systems



\- Moving piston/platform Blueprint

\- Bounce block player launch Blueprint

\- Lever Boolean toggle Blueprint



\## Controls



\- WASD to move

\- Mouse to look around

\- Space to jump

\- Interact by touching or colliding with prototype objects



\## Current Status



This is a prototype focused on Blueprint interaction logic. The current build does not include a final UI system, complete menus, or a full win/loss flow.



\## Notes



The prototype uses Unreal Engine basic shapes and Blueprint scripting. The main focus is on testing gameplay interactions, collision events, Boolean variables, casting, movement logic, and debugging.
